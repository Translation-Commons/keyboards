Start Using Miship

Spoken by: The Miship people of Miship land, Pankshin Local Government Area, Plateau State, Nigeria

Keyboard Layout

Type as normal for all standard Latin letters. Hold down a key on a touch device, or use AltGr (Right Alt) on a physical keyboard, to reach the special Miship letters:

b → ɓ    d → ɗ    g → ɣ    h → ɦ    i → ɨ    n → ŋ, ṇ    m → ṃ    s → ʃ    z → ʒ
